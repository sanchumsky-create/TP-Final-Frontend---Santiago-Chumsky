Decidí tomar el desafío de continuar desarrollando el WhatsApp Web que fue sugerido en clase, agregándole más funciones y
perfeccionando lo visual, agregándole estilos lo más parecido al original usándolo a todo momento para ir comparando estilos, colores y la fuente.
Tuve dificultades en ciertos aspectos visuales por lo que recurrí a usar distintas IA para ver si el camino que fui tomando era el correcto.

La mayoría de la aplicación es nativa de React, importe distintos elementos como la fuente idéntica a WhatsApp, el logo de dicha aplicación, el logo para la configuración de la aplicación y los fondos de los dos temas (Claro y Oscuro).

Opencode: Esta IA la utilice mayormente en modo "plan" para ir viendo si había maneras de optimizar el programa y en los momentos que lo use en modo "build" fue solo para modificar css ya que siento que es la parte que tengo más afianzada a la hora de crear el desafío y decidí recortar tiempo en esos casos.
